역할
- 1인 개발로 기획, 클라이언트 구현, 서버 연동까지 전 과정을 담당했습니다.

프로젝트 소개
- Unity 2D 기반의 디펜스 게임으로, 서버 연동까지 구현한 1인 개발 포트폴리오 프로젝트입니다.

핵심 기술
- Unity 2D / C#
- TCP 소켓 통신 (SuperSocketLite)
- MessagePack 패킷 직렬화
- MongoDB — 유저 인증 시스템 (회원가입, 로그인, 비밀번호 변경, 계정 삭제)
- RedisDB — 채팅 시스템 (채팅방 생성/참가/퇴장, 채팅 내역, 랭킹)
- MVP 패턴 / 멀티스레딩 / 오브젝트 풀링

AI 활용
- Gemini — 게임 내 이미지 제작 (배경, 타이틀 등)
- Claude CLI — 모르는 개념 학습 및 구현 보조
